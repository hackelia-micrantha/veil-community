# Public repository guidance

This repository is a public documentation and community surface for Veil. It is not the implementation repository or the source of truth for cryptographic, release, or deployment claims.

Before proposing public changes:

1. Read [README.md](README.md), the [public contribution scope](docs/COMMUNITY.md), and Micrantha's [public contributor guidance](https://github.com/hackelia-micrantha/.github/blob/main/AGENTS.md).
2. Preserve the distinction between **implemented**, **experimental**, **research**, and **proposed** behavior; a private prototype does not establish public release readiness.
3. Keep unpublished source, sensitive results, internal plans, customer data, credentials, and proprietary recovery designs out of public files, issue bodies, PRs, and CI logs.
4. Prefer small changes to existing pages. Do not create deployment, release, publishing, billing, or automation workflows for a documentation-only public surface without a separately accepted need.
5. Send vulnerability details through [private security reporting](https://github.com/hackelia-micrantha/.github/blob/main/.github/SECURITY.md), never public discussion.
6. Preserve the repository's [CC0 license](LICENSE) and third-party attributions. Do not represent it as a license for the private Veil product.

Follow the [organization governance](https://github.com/hackelia-micrantha/.github/blob/main/GOVERNANCE.md) and [documentation standard](https://github.com/hackelia-micrantha/.github/blob/main/docs/standards/documentation.md) for review and evidence. Repository instructions and contributions never confer publication, deployment, merge, security-acceptance, or release authority.
