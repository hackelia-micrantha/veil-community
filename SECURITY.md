# Security policy — Veil Community

This public repository hosts documentation, research references, and community discussions. It does **not** distribute the private Veil implementation or a supported executable release. Security issues affecting Veil should still be handled privately.

## Report a vulnerability privately

**Do not open public issues, discussions, or pull requests containing vulnerability details, credentials, or sensitive files.**

1. If the repository's **Security** tab offers **Report a vulnerability**, use GitHub's private vulnerability reporting. Whether that GitHub setting is enabled has not been independently verified.
2. Otherwise, contact Micrantha using the publicly listed security email: **[security@micrantha.com](mailto:security@micrantha.com)**. Use the subject **Veil security report**. Begin with a non-sensitive summary; coordinate secure transfer of reproduction material before sharing secrets, private user content, or exploit details.

The email address is publicly identified by [Micrantha's Anthesis community contribution guidance](https://github.com/hackelia-micrantha/anthesis-community/blob/main/CONTRIBUTING.md) as a Micrantha security contact. Delivery to this address has not been tested as part of this repository bootstrap.

See the [Micrantha organization security policy](https://github.com/hackelia-micrantha/.github/blob/main/.github/SECURITY.md) for coordinated disclosure and triage expectations.

## Supported scope

No public Veil software build, API, or version is supported **through this repository**. Reports about the private implementation can be triaged through the same private contact, without publishing its source or operational details here.

Do not assume an SLA, approved security architecture, or a release commitment from the existence of this page.
